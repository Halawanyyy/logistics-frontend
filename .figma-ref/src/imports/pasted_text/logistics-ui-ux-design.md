Design a **next-generation, ultra-modern UI/UX** for a web-based **Logistics, Shipping, and Warehouse Management System**.

This is not a basic dashboard.
This should feel like a **premium, world-class SaaS product** used by high-scale logistics companies.

---

## 🔥 DESIGN DIRECTION (VERY IMPORTANT)

* Style: **Minimal, futuristic, data-first**
* Inspired by: Linear, Stripe, Notion, Vercel, Ramp
* Clean but **highly structured**
* Strong grid system
* High attention to spacing and alignment
* Subtle micro-interactions (hover, focus, transitions)
* No clutter, no unnecessary elements
* Focus on **clarity + speed of use**

---

## 🎨 VISUAL STYLE

* Light theme (primary)
* Soft neutral background (off-white / very light gray)
* 1 strong primary brand color (modern green or blue)
* Accent colors for statuses only (success, warning, danger, info)
* Glass effect or soft elevation for cards (very subtle)
* Smooth rounded corners (not too playful)
* Modern typography (clean, readable, strong hierarchy)

---

## 🧠 UX PRINCIPLES (CRITICAL)

* Design for **operators, not viewers**

* Every screen should answer:
  → What is happening?
  → What should I do next?

* Reduce cognitive load

* Make heavy data **easy to scan in seconds**

* Use:

  * Progressive disclosure
  * Smart grouping
  * Contextual actions (not everything visible at once)

* Avoid long forms → use steps / sections

---

## 🧩 GLOBAL APP EXPERIENCE

Design a consistent app shell with:

* Collapsible smart sidebar (icons + labels)

* Sticky top bar with:

  * Global search (VERY IMPORTANT)
  * Notifications
  * Quick actions (Create Shipment, Add Item, etc.)
  * User menu

* Command palette (like CMD + K)

* Page header:

  * Title
  * Context info
  * Inline actions (not separate buttons everywhere)

---

## ⚡ ADVANCED UX FEATURES (MAKE IT UNIQUE)

Include:

* Command palette (keyboard-driven navigation)
* Smart filters (dynamic + saved views)
* Inline editing in tables
* Slide-over panels instead of page reloads
* Real-time status updates (simulate)
* Activity timeline components
* Multi-tab detail pages (like Notion/Stripe)
* Quick preview on hover or click
* Bulk actions UX (very smooth)

---

## 🔐 AUTHENTICATION (PREMIUM EXPERIENCE)

Design:

* Login
* Forgot password
* Reset password
* OTP verification

Style:

* Split layout
* Left: minimal form

* Subtle animation or gradient
